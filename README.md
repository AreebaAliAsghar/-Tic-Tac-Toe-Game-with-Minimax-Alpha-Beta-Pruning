# 🎮 Tic-Tac-Toe AI (Minimax with Alpha-Beta Pruning)

This project implements a classic **Tic-Tac-Toe** game in Python where you play against an intelligent AI powered by the **Minimax algorithm** with **Alpha-Beta pruning**.

The AI evaluates optimal moves based on a depth-limited search strategy combined with a simple heuristic function — making it a great demo of adversarial search techniques from artificial intelligence.

---

## 📌 Features

- ✅ 3x3 interactive board in terminal
- 🤖 AI opponent using Minimax + Alpha-Beta Pruning
- 🎯 Custom heuristic evaluation at limited depth
- 🚫 Detects invalid moves
- 🏆 Declares win, draw, or loss based on game state

---

## 🧠 AI Logic

- **Minimax** explores possible future game states.
- **Alpha-Beta pruning** improves efficiency by cutting off unneeded branches.
- **Heuristic Function** scores non-terminal states when depth limit is reached.
- Depth is dynamically increased if AI can't find a move (optional logic).
